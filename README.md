## About

I build the control layer for autonomous AI systems: how work is decomposed, routed across models and agents, checked against evidence, and recovered when a step fails. The focus is practical middleware and evaluation for multi-agent deployment, not another chat wrapper.

- **Building** [OMK](https://github.com/dmae97/omk), an open-source TypeScript coding agent with model switching and test-backed goals.
- **Researching** [AdaptOrch](https://arxiv.org/abs/2602.16873), task-adaptive orchestration across parallel, sequential, hierarchical, and hybrid topologies.
- **Shipping** [AdaptOrch](https://adaptorch.com), evidence receipts for AI-written code.
- **Interests** model routing, adaptive synthesis, verification-guided inference, and agent evaluation.
